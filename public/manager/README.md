# RP Website Manager

This is the first local control centre for the RP Bookkeeping website.

Open `/manager/` on a running copy of the site.

## Current capabilities

- Responsive manager interface
- Local browser draft storage
- Editable core site fields
- Export content as JSON
- Website preview iframe
- Reset local draft

## Important

This first version does **not** publish changes to the public website and does **not** provide authentication yet. That is intentional: authentication, server-side storage, backups and publishing will be added before the manager is exposed to the public internet.
